## Key Decisions

No ADR written this session (none crossed the rule 11 bar). Implementation choices worth recording:
1. Import/Export is its own bounded context that reuses the existing domain commands rather than duplicating row-construction logic — an import failure rolls back on the same transactional guarantees the commands already provide.
2. Imports are all-or-nothing: a project import rolls back entirely on any rejected step, and a card-import row error writes nothing for the whole batch rather than skipping the bad row.
3. Imported dependencies always receive fresh numbers rather than replaying the source project's numbers, avoiding cross-project number collisions.
