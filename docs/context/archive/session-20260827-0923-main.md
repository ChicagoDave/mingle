## Key Decisions

### 1. Built as MQL `AS OF`, not a bespoke history query
`mql-projection.server.ts` had refused `AS OF` by name as "Phase 18's subject" — this phase built it properly instead of writing a one-off reconstruction. A second in-memory reconstruction inside the chart macro was considered and rejected: it would let a filter and a chart disagree about `Status != Open` on an unset property, with both answers looking correct and no test catching the drift. `CardSource` exists specifically so `currentCards` and `cardsAsOf` share one unset-property rule. `AS OF` now works everywhere MQL does (filters, table/value macros, projection), not only in this chart. Recorded in `docs/adrs/0015-historical-reads-are-a-card-source-substitution.md` (ACCEPTED, 7 decisions).

### 2. Two deliberate divergences from legacy
Legacy's `AS OF` join inner-joins the live `cards` table inside its `MAX(version)` subquery, so a card deleted after the as-of date silently vanishes from its own history. This schema keeps versions on delete and marks the final one `is_deletion` precisely so history reads independent of current state — a card is present every day up to deletion and absent after. Separately, no OSS charting library was added, despite the plan entry's original wording: Phase 17 (ADR-0014) had already settled charts as server-rendered inline SVG so they render with scripting off and pass the existing allowlist; adding a JS library would have contradicted a shipped decision to satisfy a bullet written before it. Phase 19 inherits this.

### 3. ADR-0015 review findings, both fixed before ACCEPTED
Decision 4 originally claimed `AS OF` reached "the filters" — it does not; the list-view advanced filter refuses it by name and always did (accepts bare conditions only). Narrowed to name that exception. Separately, ADR-0006's consequences already cite "chart macros and the daily-history reconstruction" as the strongest existing support for the translation approach, and the new ADR hadn't quoted it — now quoted in Context. Writing the ADR also surfaced the nested-`AS OF` silent-ignore bug fixed above.
