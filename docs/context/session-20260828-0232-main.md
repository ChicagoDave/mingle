### Session-start phase-detection bug (fixed at the DevArch source repo, not part of this commit)
Root cause of the three-session-old open item ("banner read Phase 12 while plan.md was at 25/26"): `~/repos/devarch/docs/workflow/hooks/session-start.sh` matched `grep -q "Status.*CURRENT"` over a fixed 8-line window following each `### Phase` heading. Two independent bugs — (a) Phase 12's DONE-status prose contains text resembling "CURRENT USER" hints that satisfied the pattern first, and (b) the fixed window bled into the next phase's Status line whenever phases are spaced ≤8 lines apart. Fixed by rewriting the matcher as an awk walk that bounds each phase block by the next `###` heading and matches only `^(- )?\*\*Status\*\*: CURRENT` (Tier/Budget extraction bounded the same way). Patched the source plus both installed copies (`~/.devarch/hooks`, `~/.claude/hooks`) so the fix took effect this session.
