## Key Decisions

### 1. Derived facts become stored facts (ADR-0017)
Mention resolution and card-comment linkage were recomputed/queued at read time in legacy; both are now written inside the posting transaction, making "who was mentioned" and "which card a murmur belongs to" queryable facts rather than approximations. ADR-0017 (ACCEPTED) covers 8 decisions, including the deleted-card origin fix found by `adr-review`.

### 2. Shared grammar lives in a cross-context kernel module
The `#123` card-reference grammar moved out of a private constant in `pages/content.server.ts` into `app/domain/text-references.server.ts`, imported by both Wiki & Content and Collaboration — avoiding the two-renderings-disagree failure class ADR-0015/0016 were written about.

### 3. History/Atom feeds project over version trails, not domain_events
`domain_events` is command-shaped with no snapshot; a feed built on it would rewrite its own history on every rename. The feed instead unions `card_versions`/`page_versions`/`murmurs` in one compound SQL SELECT (ADR-0016), accepting an arbitrary-but-stable tie-break since the three trails share no sequence.

### 4. Feeds narrowed to session authentication
Legacy served feeds under a separate API credential scheme this rewrite does not yet have; the rewrite refuses unauthenticated feed access rather than serving it — the conservative side of that gap.
